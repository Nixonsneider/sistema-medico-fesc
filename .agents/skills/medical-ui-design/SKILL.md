# Medical System UI/UX Design

## 1. Objetivo

Diseñar interfaces profesionales, modernas, sobrias y funcionales,
propias de un sistema de gestión médica real.

Evitar diseños genéricos generados por inteligencia artificial.
Priorizar la eficiencia, claridad, usabilidad y confianza visual
sobre los elementos decorativos.

## 2. Identidad visual

- Mantener una estética clínica, limpia y profesional.
- Utilizar colores neutros, blancos, grises y azules suaves.
- Reservar los colores intensos para acciones y estados importantes.
- Utilizar una tipografía legible y consistente.
- Mantener bordes ligeramente redondeados (4px a 8px).
- Utilizar sombras sutiles únicamente cuando sean necesarias.
- Mantener un espaciado equilibrado entre elementos.
- Evitar tanto la saturación visual como el minimalismo excesivo.
- Respetar la identidad visual existente del proyecto.

## 3. Diseños prohibidos

- Degradados decorativos innecesarios.
- Glassmorphism y efectos de cristal.
- Colores neón o excesivamente llamativos.
- Bordes exageradamente redondeados.
- Tarjetas dentro de otras tarjetas sin justificación.
- Tarjetas para absolutamente todos los elementos.
- Títulos gigantes y encabezados desproporcionados.
- Emojis como sustitutos de iconos.
- Animaciones que no aporten funcionalidad.
- Fondos con formas abstractas decorativas.
- Espacios vacíos excesivos.
- Diseños propios de landing pages comerciales.
- Componentes visuales que parezcan plantillas genéricas de IA.

## 4. Componentes de interfaz

### Navegación

- Mantener una navegación clara, compacta y consistente.
- Utilizar menús laterales cuando sean apropiados.
- Identificar visualmente el módulo activo.
- Evitar elementos decorativos en la navegación.

### Tablas

- Priorizar la legibilidad y organización de los datos.
- Utilizar encabezados claros.
- Mantener filas compactas pero cómodas de leer.
- Alinear correctamente fechas, números y textos.
- Incorporar filtros, búsquedas y paginación cuando corresponda.
- Utilizar indicadores discretos para los estados.

### Formularios

- Organizar los campos en grupos lógicos.
- Utilizar etiquetas explícitas y visibles.
- Mostrar validaciones comprensibles.
- Diferenciar campos obligatorios y opcionales.
- Evitar formularios innecesariamente extensos.
- Mantener una jerarquía clara entre acciones principales
  y secundarias.

### Dashboards

- Mostrar información realmente relevante para el usuario.
- Utilizar tarjetas estadísticas solo cuando aporten valor.
- Priorizar citas, pacientes, alertas y actividad clínica
  según las necesidades del módulo.
- No inventar métricas ni información decorativa.
- Utilizar gráficos únicamente cuando faciliten la comprensión.

### Botones e iconos

- Mantener tamaños y estilos consistentes.
- Diferenciar acciones primarias, secundarias y destructivas.
- Utilizar iconos profesionales de una misma biblioteca.
- Evitar múltiples botones primarios en una misma sección.

## 5. Experiencia de usuario médica

- Reducir los pasos necesarios para completar una tarea.
- Priorizar la rapidez de interacción.
- Facilitar la consulta y registro de información.
- Diferenciar claramente los datos clínicos y administrativos.
- Mostrar estados de carga, error, éxito y ausencia de datos.
- Solicitar confirmación para operaciones destructivas.
- No depender exclusivamente del color para comunicar estados.
- Garantizar contraste, accesibilidad y navegación por teclado.
- Evitar exponer datos sensibles innecesariamente.

## 6. Reglas de implementación

Antes de crear o modificar una interfaz:

1. Revisar las vistas y estilos existentes.
2. Identificar componentes reutilizables.
3. Mantener coherencia con los demás módulos.
4. Priorizar la funcionalidad sobre la decoración.
5. Respetar las tecnologías frontend existentes.
6. No introducir nuevas dependencias sin justificación.
7. Garantizar adaptabilidad a diferentes resoluciones.
8. Evitar modificar la lógica de negocio por razones estéticas.
9. Verificar que la interfaz final sea consistente y profesional.

## 7. Criterio final de calidad

Antes de finalizar cualquier cambio visual, comprobar:

- ¿Parece un sistema médico real?
- ¿Es intuitivo y eficiente?
- ¿Existe una jerarquía visual clara?
- ¿Mantiene coherencia con el resto del sistema?
- ¿Hay elementos decorativos innecesarios?
- ¿Se evita la apariencia genérica de interfaces creadas por IA?

Si un elemento no aporta información, funcionalidad
o claridad, considerar simplificarlo o eliminarlo.
