
# Instrucciones del proyecto

## Diseño de interfaces

Antes de crear, modificar o revisar cualquier interfaz
de usuario, vista web, componente o estilo CSS, debes
leer y aplicar obligatoriamente las instrucciones de:

.agents/skills/medical-ui-design/SKILL.md

Estas directrices deben respetarse en todos los módulos
del sistema, incluso cuando el usuario no las mencione
explícitamente en su solicitud.
